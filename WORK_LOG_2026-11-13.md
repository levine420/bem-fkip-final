### 2. Database Connection Fix

**Masalah:** 
- Error: `Timed out fetching a new connection from the connection pool`
- Database connection pool timeout karena connection limit = 1

**Solusi:**
1. Ganti dari Supabase **Direct Connection** (port 5432) ke **Connection Pooler** (port 6543)
2. Tambahkan parameter `pgbouncer=true` untuk disable prepared statements
3. DATABASE_URL baru: `postgresql://postgres.xxx:PASSWORD@aws-0-ap-southeast-1.pooler.supabase.com:6543/postgres?pgbouncer=true`

**Status:** ✅ Berhasil - connection pool timeout solved

### 5. Image Upload Fix (Latest Issue)

**Masalah:** Upload banner/gambar saat edit konten gagal dengan error 503 (Service Unavailable).

**Root Cause:**
- Error code: `P2000` - "The provided value for the column is too long for the column's type"
- Upload route sebelumnya fallback ke **base64 data URL** jika tidak bisa simpan ke local filesystem
- Base64 data URL sangat panjang (100KB+ gambar = 140KB+ base64 string)
- Database column `thumbnail_url` hanya VARCHAR(1024) - tidak cukup untuk base64

**Solusi yang Diimplementasi:**
1. Update upload route (`src/app/api/admin/upload/route.ts`) untuk:
   - Upload ke Vercel Blob Storage (cloud storage otomatis di Vercel)
   - Fallback ke local filesystem dengan kompresi gambar
   - Hapus fallback base64 yang menyebabkan error

2. Install dependencies: `@aws-sdk/client-s3` untuk Supabase Storage

**Files Changed:**
- `src/app/api/admin/upload/route.ts` - Complete rewrite untuk cloud storage
- `package.json` - Added AWS SDK dependency

**Status:** ✅ Upload route sudah terupdate dan di-deploy
